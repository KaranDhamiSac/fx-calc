# fx Calc

An offline scientific calculator modeled on the Casio fx-991 series. It's a PWA: open the link once on your phone, choose **Add to Home Screen**, and from then on it runs with no internet.

Features: exact fractions, surds and π results (S⇔D), history, variables A–F/X/Y/M, STO/RECALL, M+/M−, CALC, SOLVE, ∫, d/dx, Σ, ∏, nPr/nCr, Pol/Rec, DMS, ENG, FACT, constants, unit conversions, and Statistics, Table and Equation (simultaneous and polynomial) modes.
